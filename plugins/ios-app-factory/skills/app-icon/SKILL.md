# App icon (stage `app_icon`)

Inputs: `design.json` (concept, palette), `charter.json` (principles), `aso.json` (name, subtitle, keywords,
category), `research.json` (competitors — the icons your icon will sit next to in search results).
Outputs:
- `factory/artifacts/app_icon/icon.json` — schema `${CLAUDE_PLUGIN_ROOT}/lib/appfactory/schemas/app_icon.schema.json`
- `factory/artifacts/app_icon/icon.md` — concept, rationale, ASO reasoning, previews described (≥200 chars)
- `App/Resources/Assets.xcassets/AppIcon.appiconset/*` — generated by `app-factory icon render` (never hand-edit)

Example: `${CLAUDE_PLUGIN_ROOT}/examples/sample-app/factory/artifacts/app_icon/icon.json`.

## 1. Think before drawing
1. **Charter**: which principle does the icon embody? (`concept.derived_from_principles`)
2. **Design concept**: same visual world (`concept.design_concept` = design.json concept name; colours from the
   design palette — any other colour needs an `extra_colors` entry with a reason).
3. **ASO** (`aso` block):
   - `keywords_reflected`: which words from the store name/subtitle/keywords the motif makes visible at a glance
     (an icon that "says" the keyword improves tap-through from search).
   - `differentiation`: look at the competitors' icons (open their App Store pages from research) and state how
     yours stands apart (colour field, silhouette). Avoid the category clichés.
   - `small_size_strategy`: how it still reads at 60px (one silhouette, high contrast, ≤2 detail elements).
4. **Apple HIG — App icons** (required reference): https://developer.apple.com/design/human-interface-guidelines/app-icons —
   single focus point, no words/letters (the name is shown under the icon), no photos or UI screenshots, fill the
   square (the system applies the corner mask), opaque background, provide dark and tinted appearances.
   Use Anthropic's `frontend-design` skill (if installed) to challenge default-looking choices.
5. List at least two `avoided` clichés.

## 2. Draw it as a spec
`icon.json` layers use unit coordinates (0–1 of the 1024px canvas). Shapes: `circle`, `ring`, `ellipse`, `rect`,
`rounded_rect`, `polygon`, `line`, `arc`. Each layer has a `role` (`glyph` = the main motif, `accent`, `detail`), a
`fill` and optionally `dark_fill` and `opacity`. `background` is solid or gradient. `dark_background` sets the dark
appearance. The tinted variant is derived automatically. No text layers exist on purpose.
A human-made PNG can be used instead with `source_png` (and optional `source_png_dark`) — the gate still checks traceability.

## 3. Render, look, iterate
```
app-factory icon render     # → AppIcon-1024.png (+ -dark, -tinted) and Contents.json
app-factory icon preview    # → .factory-tmp/icon-preview.png at 60/120/180px on light & dark wallpapers
```
Open the preview with the Read tool and judge it honestly: is the motif identifiable at 60px? Does it look like
*this* app and not a template? Iterate at least once.

Gate (`app-factory gate app_icon`): schema; principles exist; design concept and App Store name match; reflected
keywords come from ASO metadata; HIG referenced; colours from the design palette; a glyph layer with ≥3:1 contrast in
light and dark; ≤12 layers; artwork covers 12–75% of the icon at 64px; rendered set up to date; main icon 1024×1024 RGB without alpha.
